Follow one request

  1. Retrieve. An AI Search endpoint serves an index. A Delta Sync index follows a source table; a Direct Vector Access index needs application-managed updates. The retriever sends a query and receives matching passages. Index types; retrieval.
  2. Generate. The chain places the selected passages into the model input, calls a foundation model endpoint, and formats the answer. Pay-per-token Foundation Model APIs provide preconfigured model endpoints; provisioned throughput supplies dedicated capacity when needed. Chain stages; Model choices.
  3. Deliver. A Databricks app can host agent code, a chat UI, and an API. A custom MLflow pyfunc can package preprocessing, prediction, and postprocessing as a registered model and be served through Model Serving. Databricks recommends Apps for new agents. Apps; pyfunc; deployment guidance.

Try the packaging step in a notebook

This small chain has no external endpoint or data dependency. It proves the shape of preprocessing, prediction, and postprocessing before you swap in a retriever and LLM. Use a Databricks notebook with MLflow installed. Custom pyfunc guide; Input example and signature guide.

import mlflow
import pandas as pd
from mlflow.models.signature import infer_signature

class TinyChain(mlflow.pyfunc.PythonModel):
    def predict(self, context, model_input):
        questions = model_input["question"].str.strip()  # preprocess
        drafts = questions.map(lambda q: f"Draft for: {q}")  # stand-in model
        return drafts.map(lambda text: text + " [demo]")  # postprocess

example = pd.DataFrame({"question": ["  How do I reset a job?  "]})
model = TinyChain()
signature = infer_signature(example, model.predict(None, example))

with mlflow.start_run():
    info = mlflow.pyfunc.log_model(
        name="tiny_chain",
        python_model=model,
        input_example=example,
        signature=signature,
        pip_requirements=[f"mlflow=={mlflow.__version__}", f"pandas=={pd.__version__}"],
    )

print(mlflow.pyfunc.load_model(info.model_uri).predict(example))

The output should be Draft for: How do I reset a job? [demo]. This only tests packaging and local inference; it does not create a RAG index or endpoint. When registering a real model, use mlflow.set_registry_uri("databricks-uc") and a three-level registered_model_name. Unity Catalog registration; Dependency requirement.
