2. Pyfunc owns the request boundary

A custom mlflow.pyfunc.PythonModel lets you package preprocessing, model calls, branching, and postprocessing together. Put reusable initialization in load_context(self, context); put per-call work in predict(self, context, model_input, params=None). Initialization happens when an instance loads, so “once” does not mean once across every serving replica. Custom Python models; Replica behavior.

load_context: load packaged files; initialize reusable components

predict:
    incoming request
      → validate and normalize input
      → retrieve evidence → build prompt → call LLM
      → parse answer and format citations
      → return the public output structure

This is an illustrative RAG flow. Databricks separates query processing, retrieval, prompt augmentation, generation, and post-processing when diagnosing RAG quality. RAG components.

Helpers named format_inputs or format_outputs are your code. Call them from predict; their names alone do not make them execute. Input processing placed only in a notebook cell is absent from the wrapper's prediction path. Wrapper example.

For generic custom Python behavior, use PythonModel. For an existing supported LangChain chain, consider its native logging flavor. For a conversational agent needing Databricks chat and streaming integration, Databricks recommends ResponsesAgent, whose request and response schemas differ from this lesson's tabular wrapper. It can wrap an existing framework and gets automatic signature inference. LangChain logging; ResponsesAgent.

There is no universal “RAG contents” list independent of your logging call. A flavor is the format and loading convention for a model. The same application also has configuration, files, Python dependencies, and remote dependencies. MLflow model formats; Agent logging.

Reasoning from that boundary. If your chain queries a hosted LLM and an AI Search index, logging their names does not copy the LLM weights, index, or source documents. The deployed code still calls those services. A small local knowledge file explicitly supplied as an artifact is a different case: that file travels with the package. External resources; File packaging.

Logging a model versus logging execution. MLflow Tracing records request execution, including intermediate retrievals, tool calls, inputs, outputs, and timing. Enable an appropriate tracing integration or instrumentation. Packaging a model is not evidence that every future execution is traced. Tracing overview.

4. Register source first, name second

registered = mlflow.register_model(
    model_uri=info.model_uri,
    name="main.training.support_rag",
)

# Same first two arguments, positionally:
registered = mlflow.register_model(
    info.model_uri, "main.training.support_rag"
)

These are alternatives; running both creates two registrations. The first argument identifies the source package. The second is the destination registered model name. Use the returned registered.version rather than guessing the next version. Registration examples; Using the returned version.

5. Lab: prove that the package travels

This exercise uses a tiny keyword lookup and returns evidence verbatim. It intentionally has no LLM, embedding model, or AI Search service. The target skill is packaging and reloading the complete input/output path. A real RAG implementation would replace the lookup with retrieval and generation.

Run in a Databricks Python notebook with MLflow 3 and pandas installed. The example uses artifacts and load_context as documented by Databricks. It pins the full mlflow package explicitly for serving compatibility. Artifacts; Full MLflow requirement.

import json
import tempfile
from pathlib import Path

import cloudpickle
import mlflow
import pandas as pd

class PackagingDemo(mlflow.pyfunc.PythonModel):
    def load_context(self, context):
        self.facts = json.loads(
            Path(context.artifacts["facts"]).read_text()
        )

    def predict(self, context, model_input, params=None):
        rows = []
        for question in model_input["question"]:
            # Preprocessing, including a content rule beyond schema types.
            query = question.strip().lower()
            if not query:
                raise ValueError("question must not be blank")
            # Toy lookup. This is not semantic retrieval or generation.
            hit = self.facts.get(query)
            # Postprocessing defines the caller's output structure.
            rows.append({
                "answer": hit["text"] if hit else "No evidence found.",
                "source": hit["source"] if hit else "",
            })
        return pd.DataFrame(rows, columns=["answer", "source"])

example = pd.DataFrame({"question": ["  PACKAGING  ", "unknown"]})
expected = pd.DataFrame({
    "answer": ["This fact traveled with the model.", "No evidence found."],
    "source": ["demo-note", ""],
})

with tempfile.TemporaryDirectory() as folder:
    facts_path = Path(folder) / "facts.json"
    facts_path.write_text(json.dumps({
        "packaging": {
            "text": "This fact traveled with the model.",
            "source": "demo-note",
        }
    }))
    with mlflow.start_run():
        info = mlflow.pyfunc.log_model(
            name="packaging_demo",
            python_model=PackagingDemo(),
            artifacts={"facts": str(facts_path)},
            input_example=example,
            signature=mlflow.models.infer_signature(example, expected),
            pip_requirements=[
                f"mlflow=={mlflow.__version__}",
                f"pandas=={pd.__version__}",
                f"cloudpickle=={cloudpickle.__version__}",
            ],
        )

# The original temporary facts file has now been deleted.
loaded = mlflow.pyfunc.load_model(info.model_uri)
actual = loaded.predict(example)
pd.testing.assert_frame_equal(actual, expected)
print(info.model_uri)
display(actual)

Expected result: the padded uppercase input finds the packaged fact, and the unknown input returns an empty source. The assertion checks both branches after reloading, with the original file gone. Object-based logging keeps this lab in one cell; use the recommended Models from Code approach for an agent project.

In a second cell, choose an existing catalog and schema where you may create models. New registrations require USE CATALOG, USE SCHEMA, and CREATE MODEL. New UC model versions need a signature. Prerequisites.

mlflow.set_registry_uri("databricks-uc")
model_name = "YOUR_CATALOG.YOUR_SCHEMA.packaging_demo"
registered = mlflow.register_model(
    model_uri=info.model_uri,
    name=model_name,
)
version_uri = f"models:/{model_name}/{registered.version}"
reloaded = mlflow.pyfunc.load_model(version_uri)
pd.testing.assert_frame_equal(reloaded.predict(example), expected)
print(model_name, registered.version)

6. Mistakes worth catching

  • Notebook imports mistaken for dependencies. Package helper code with code_paths and review requirements. Ordinary Python imports in the authoring notebook are not a deployment plan. Dependency packaging.
  • Schema mistaken for behavior. A string-typed question can still be blank. A signature supports input enforcement; your code must implement content rules and output formatting. Signature enforcement.
  • Resources mistaken for credentials. Declare dependencies for automatic authentication, then Databricks verifies the deployer's access and provisions short-lived credentials. Per-user authorization requires the separate on-behalf-of-user configuration. Initialize user-specific access during prediction. Authentication methods.
  • Model version mistaken for a frozen world. An unchanged package can behave differently if a live retriever, endpoint, or dynamically loaded prompt changes. Record those dependencies when investigating a regression. This follows from the documented external-resource and dynamic-prompt design. Runtime resources.
