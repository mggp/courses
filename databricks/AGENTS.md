# Databricks lessons site

The GitHub Pages landing page for this project is [`../index.html`](../index.html).
It lists the lessons under `lessons/` and links to their shared stylesheet.

When adding, removing, renaming, or substantially revising a lesson, update
`../index.html` in the same change so its lesson links and summaries stay
accurate. Keep the landing page focused on lessons; maintain detailed
references within the lesson pages.
