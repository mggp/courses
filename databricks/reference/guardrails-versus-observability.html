Guardrails versus observability

Need to prevent this call or response? Use a service policy. Need to explain an agent run or measure quality? Use MLflow traces and scorers. Policy source; observability source.

NeedMechanism
Who can invoke a Model Service?Unity Catalog EXECUTE privilege. Source.

Inspect or block a model reply before delivery?Service policy, ON RESULT. Source.
Find an agent's slow or wrong step?MLflow trace and child spans. Source.
Measure live answer quality?MLflow production monitoring, with scorers on sampled traces. Source.
Track gateway requests, tokens, and latency?system.ai_gateway.usage. Source.

Policy result. ALLOW proceeds. DENY blocks but returns an HTTP 200 assistant turn and a databricks_service_policy reason. ASK pauses for approval. Source.

Availability and scope. Service policies are beta and need the account preview. They attach to Model Services, Model Provider Services, and MCP Services, not Agent Services. Log mode observes a would-be decision without blocking. Scope; Log mode.
