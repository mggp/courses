Batch inference and MCP

ai_query transforms selected data with a model. MCP lets an agent discover and call tools. Start there.

CueDecision

Fast eliminations

  • ai_query invokes an existing endpoint. It does not deploy one. Source.
  • returnType is not responseFormat. The former describes a custom endpoint's return type; the latter constrains chat-model output. Source.
  • An MCP Service is a governed Unity Catalog object, not a generic name for all MCP servers. Source.
  • The current managed list has no web-browser MCP server. Source.
  • Network reachability and Unity Catalog permissions are independent for external MCP Services. Source.
