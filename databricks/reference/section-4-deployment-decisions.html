Retrieve

Exam cueDecision
Create and query an indexCreate an AI Search endpoint, then an index. Query with the SDK, REST API, or SQL vector_search function. For a text query through the SDK, use similarity_search(query_text=..., columns=..., num_results=...). Create; Query.
Source table drives updatesDelta Sync index. Continuous sync favors freshness and costs more; triggered sync favors scheduled updates. Direct Vector Access means your application updates vectors itself. Storage-optimized endpoints support triggered sync, with partial index rebuilds. Source.
Scale, latency, costStandard endpoints support about 320 million vectors at dimension 768 and high QPS. Storage-optimized endpoints exceed one billion, index 10–20 times faster, and add about 250 ms query latency. Check current limits and pricing before choosing. Source.
Exact identifier plus semantic wordingHybrid search combines keyword and vector retrieval; filters narrow candidates and reranking adjusts result order. Source.

Run and govern

Exam cueDecision
Use a foundation modelCall a preconfigured pay-per-token Foundation Model APIs endpoint for a quick start. Use provisioned throughput when dedicated capacity is required. The foundation model endpoint serves the LLM; the app or chain supplies retrieval and orchestration. Source.
Interactive applicationDatabricks Apps is the current recommended home for a new custom agent and can provide a chat UI and API. A registered custom model can still run on a Model Serving endpoint. Agent deployment; Apps; Model Serving.
Control who calls a serving endpointGrant CAN QUERY to callers. The endpoint creator needs the required Unity Catalog privileges on the served model and its dependencies. Endpoint ACL; Creator grants.
Inference over many table rowsUse the ai_query SQL function with a supported model service or existing Model Serving endpoint. Start with a task-specific AI Function when it fits; use ai_query for custom prompts, parameters, output formats, or models. Submit the full dataset in one query and consider failOnError => false for large runs. Batch guidance; Function; decision sheet.
Conversation or durable memoryManaged agent sessions persist conversation state within an interaction. Managed agent memory holds facts that should survive into separate conversations. Both are backed by Lakebase. Use self-managed Lakebase storage when you need direct SQL or a custom schema. Managed state; Self-managed.

Managed servers; external registration; custom hosting; decision sheet.
Prompt lifecycleRegister prompt versions in MLflow Prompt Registry. Point a dev, staging, or production alias to the approved version; deployed apps can load by alias. This feature is beta. Source.
CI/CDKeep code and resource definitions in Git, test chain components, then deploy with Declarative Automation Bundles. A triggered Delta Sync index must be synced after data changes; promoting a prompt means updating its alias. CI/CD; Index sync; Prompt aliases.
User-facing interfaceChoose a Databricks app when you need a custom chat or form interface close to Databricks services. An existing workplace client such as Slack or Teams is an integration choice that depends on the organization; the guide names these channels but does not prescribe one. Apps; Exam wording.

Common mistakes

  1. Choosing Direct Vector Access and expecting source-table sync. Source.
  2. Choosing continuous sync on a storage-optimized endpoint. It supports triggered sync. Source.
  3. Assuming ai_query creates an endpoint. It invokes one that exists. Source.
  4. Granting endpoint CAN QUERY while leaving the endpoint creator without required resource grants. Source.
  5. Putting conversation history only in a process variable and expecting it to survive a restart. Use a persistent session store for resumable interactions. Source.
  6. Hardcoding a production prompt version when the app is meant to follow approved prompt changes. Use a Prompt Registry alias. Source.
