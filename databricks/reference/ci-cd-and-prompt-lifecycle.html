CI/CD and prompt lifecycle

Identify the changing artifact first. That tells you whether the action is a Git merge, bundle deployment, prompt alias move, index sync, or evaluation gate.

Artifact to action

ArtifactVersion or stateRelease action
Agent code and Databricks resource configurationGit commit plus bundle definitionValidate and deploy a Declarative Automation Bundle to a target. Source.
PromptImmutable MLflow Prompt Registry versionEvaluate the numbered version, then point the target alias at it. Source.
Retrieval documents or rowsSource Delta table or view and AI Search index stateUpdate the source; sync a triggered index or let a continuous index update. Source.
Quality decisionEvaluation dataset, scorers, traces, and resultsCompare candidate and baseline with the same evaluation setup before promotion. Source.

Prompt lifecycle

NeedMechanism
Create or change a promptCall mlflow.genai.register_prompt(). Reusing the name creates a new immutable version. Source.
Reproduce a testLoad prompts:/catalog.schema.name/7. Pin the version under test. Source.
Let an environment follow an approved promptLoad prompts:/catalog.schema.name@staging or @production. Source.
PromoteReassign the target alias to the already-tested version. Source.
RollbackReassign production to the prior version; preserve it under production-previous before promotion. Source.
Link prompt and application versionsUse an active MLflow model while loading the prompt so MLflow records lineage to the application version. Source.

Gate in this order

  1. Run deterministic unit tests for code, routing, tool arguments, filters, and error paths. Source.
  2. Deploy to an isolated pre-production bundle target and run integration tests. Source.
  3. Sync a triggered AI Search index and verify retrieval against known examples. Source.
  4. Run candidate and baseline on the same evaluation dataset and scorers. Source.
  5. Require approval where the release policy calls for it, then deploy the bundle or move the prompt alias.
  6. Monitor production traces, quality, latency, errors, and cost. Source.

Fast eliminations

  • A branch merge does not give a deployed app a movable prompt alias. Use Prompt Registry for the exam's prompt-promotion requirement. Source.
  • Overwriting a JSON file or Delta row does not provide the Prompt Registry's immutable-version and alias model for controlled rollback. Source.
  • A prompt text diff does not measure response quality. Evaluate both versions with the same data and scorers. Source.
  • A successful deployment is not a quality gate. Deployment and MLflow evaluation answer different questions. CI/CD; evaluation.
  • A triggered AI Search index is not fresh until you sync it. Source.
  • An alias is mutable. Record the resolved version when reproducibility matters. Source.
