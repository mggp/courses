Genie Agent and Conversation API

A Genie Agent supplies governed analytical meaning. The Conversation API supplies a stateful message thread. A multi-agent orchestrator decides when to call that specialist.

Name mapping. “Genie Space” in the March 2026 guide means Genie Agent in current documentation. Chat mode endpoints still use /genie/spaces/. Official concepts; official API reference.
Use Genie for
Natural-language questions over structured Unity Catalog data, with curated business semantics and generated SQL. Official source.
Keep state with
conversation_id. A follow-up in the same conversation uses previous messages. Official API reference.
Start fresh when
A new user session or unrelated analytical task begins. Cross-session reuse can leak irrelevant context into the answer. Official source.
Govern with
Genie Agent ACLs plus Unity Catalog privileges, row filters, and column masks. The configured data list is not an access boundary. Sharing source; data-list warning.
Store elsewhere
Workflow checkpoints, transactional state, user profiles, and durable application memory. Conversation history has a documented session role, not a system-of-record role.

Five-call lifecycle

  1. Start with POST /spaces/{space_id}/start-conversation.
  2. Keep conversation_id and message_id.
  3. Poll the message until COMPLETED, FAILED, or CANCELLED.
  4. Read text, query, visualization, and result attachments as needed.
  5. Send a true follow-up to /conversations/{conversation_id}/messages.

Exact endpoints and schemas: Genie API reference. Polling guidance: Use the Genie Agents API.

Security question to ask first

Whose identity calls Genie? Direct end-user access can enforce that user's Unity Catalog permissions. A Databricks App can call as its service principal or use on-behalf-of-user authorization. The answer determines which rows and columns the caller can receive. Official source.

Fast trap check

  • A configured table list improves context. It does not replace Unity Catalog authorization.
  • A conversation_id preserves analytical context. It does not become durable application memory.
  • A completed response may contain SQL and result attachments. Do not assume the text summary is the only output.
  • Chat mode handles structured data. Route document questions to a suitable document agent.
  • The SDK's ..._and_wait helpers hide polling. The REST API remains asynchronous.
