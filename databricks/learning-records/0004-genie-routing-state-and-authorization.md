# Distinguished Genie routing, conversation state, and authorization

The learner correctly selected a Genie Agent for structured-data questions, Supervisor Agent for the intended multi-specialist routing pattern, `conversation_id` for Genie follow-up context, and on-behalf-of-user authorization for per-user data access. Future practice can assume these distinctions; it should test the remaining conditional choice between a Knowledge Assistant and the current Beta capability for a Genie Agent to analyze files in attached Unity Catalog volumes.

## Evidence

In the Lesson 0002 retrieval exercise, the learner supplied the four choices above but described the document specialist only as “NOT Genie Agent,” which is too categorical under current documented product behavior.
