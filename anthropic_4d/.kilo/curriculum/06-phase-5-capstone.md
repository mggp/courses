# Phase 5 — Capstone

> Produce the final proof artifact — a Tier 3 ADR on your production system (Lead mode) and a complete written case study (Contribute mode).

## Duration

**4 weeks / ~50 hours** (12.5h/wk average)

## Weekly Breakdown

### Week 19 — Tier 3 Prep + Start ADR
- Read Tier 3 ADR methodology: irreversible decision patterns, cost/risk/mitigation structure
- Review the Tier 3 addendum template from `case-study-template.md`
- Identify a real irreversible decision on your production system (or a decision you will need to make soon)
- Start Tier 3 ADR: write Context + Constraints + Options
- **Exercise**: For each option, write a one-paragraph risk assessment
- **Hours**: 12 (4h prep + 8h ADR start)

### Week 20 — Complete ADR
- Finish Tier 3 ADR: Trade-off Analysis + Decision + Rationale + Cost/Risk/Mitigation section
- Write 3 audience-specific summaries: (a) engineering team, (b) product manager, (c) CTO
- **Exercise**: Read your ADR aloud. Does it make sense to someone outside your team? Revise for clarity.
- **Hours**: 13

### Week 21 — Case Study Write-up
- Write the Contribute-mode case study from your ADR
- Full structure: Context → Constraints → Options → Trade-off Analysis → Decision → Rationale → Outcome → Lessons
- The Outcome and Lessons sections are forward-looking (since this is a current decision) — what do you expect will happen, and what will you watch for
- **Exercise**: Ask a colleague to read the case study and tell you what's unclear
- **Hours**: 13

### Week 22 — Defense Questionnaire + Polish
- **AI session (2h)**: Tier 3 questionnaire — AI pushes on permanence with ≥5 questions
- Write answers to each question and append to the ADR as a Defense Questionnaire
- Polish both artifacts (ADR + case study)
- Flex: catch any overflow
- **Hours**: 12 (2h AI + 6h questionnaire + 4h polish/flex)

## Lead Mode Deliverable
1 Tier 3 ADR on a real production-system decision with full cost/risk/mitigation analysis and appended Defense Questionnaire.

## Contribute Mode Deliverable
1 complete case study (Context → Lessons) that a hiring manager could read and assess your architect capability.

## Influence Component
Multi-audience communication — same decision explained three ways (engineering, PM, CTO).

## Checkpoint Gate
Completed Tier 3 ADR with cost/risk/mitigation analysis. Passed defense questionnaire (≥5 answers). Case study is portfolio-ready.

## Deferral Markers
- Case study: reduce to 1-page summary (−10h)
- Skip defense questionnaire prep (−6h)
- Narrow ADR scope to a single decision (−4h)
- Final fallback: Week 22 flex absorbs up to 4h
