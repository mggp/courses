# Mapping and measuring type roles

The learner can assign purpose-based roles to interface text and inspect computed size, line height, and weight instead of judging typography by impression alone. Future practice should establish that different roles may share a type token when component context already distinguishes them; a role map is not a requirement for every role to look unique.

## Evidence

The learner correctly mapped the code-entry heading, control label, supporting copy, and action label, then supplied computed measurements for all four while holding spacing, color, and layout constant.
