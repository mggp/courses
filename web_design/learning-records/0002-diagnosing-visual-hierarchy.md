# Diagnosing visual hierarchy from attention order

The learner can state an intended attention order, observe a different order in a real interface, and connect the mismatch to scale and chromatic contrast. Future lessons can assume they understand hierarchy as an observable ordering rather than a matter of taste; the next refinement is to separate diagnosis from solution and change one variable per iteration.

## Evidence

For a one-time-code screen, the learner identified that a large reassurance heading dominates the task instruction and that a high-contrast action competes with its label. They proposed restoring the order instruction, input, explanation.
