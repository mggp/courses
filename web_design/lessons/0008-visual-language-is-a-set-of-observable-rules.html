Lesson 8 · about 10 minutes

Visual language is a set of observable rules

A visual language is not “make it premium” or “use a brutalist style.” It is the repeatable visual decisions that make the same product feel coherent and recognizably itself.

Your win: turn a vague visual direction into three testable rules an AI—or your future self—can follow.

Keep the task; change the voice

Visual language is the visible voice of a product: how typography, shape, color, surfaces, spacing, imagery, and motion repeatedly work together. It changes how an interface feels without needing to change what the person is trying to do.

That distinction matters when directing generated UI. “Make it more editorial” is a taste label. “Use a high-contrast serif for page titles, quiet paper-like surfaces, square-cornered controls, and restrained forest green” is a compact set of rules that can be inspected.

Do not let the voice erase the interface. Apple’s guidance treats typography, color, and layout as ways to communicate hierarchy and meaning; it also requires that they remain legible and adaptable across contexts.

Reserve a place

Type: one uses a high-contrast serif heading; the other uses a tight sans-serif display heading.

Geometry: one action is almost square; the other is a fully rounded pill.

Surface: one is a light, restrained paper surface; the other is a dark field with a bright accent.

Copy: both pages use the same workshop title and the same call to action.

Inspect both pages before selecting. The task and copy are deliberately held constant.

Write rules at the right resolution

Rules need enough precision to guide a second screen, but not so much that every decision becomes frozen. Start with three to five observable axes:

  1. Type: family category, contrast, weight, scale, and tightness or openness.
  2. Geometry: corner radius, border weight, icon treatment, and whether controls feel soft, sharp, or plain.
  3. Surface and color: flat or layered depth, background character, palette restraint, and where the accent is allowed.
  4. Density: compact or generous spacing; large reading areas or many simultaneous controls.
  5. Imagery and motion: documentary or abstract images; quiet or expressive transitions. Use only when they support the task.

A direction becomes useful when you can point to two examples and say whether each rule was followed. That is the bridge from visual language to the system of decisions in Lesson 7.

Protect meaning and access

Color may create continuity and personality, but it cannot be the only signal for state or interactivity. Similarly, typography can set a tone only if people can still read it at their chosen text size. A visual language is successful when its rules reinforce hierarchy and interaction contracts—not when it makes a static screenshot memorable.

Write the critique

“Keep the task flow and hierarchy, but use an editorial visual language: high-contrast serif display type, off-white surfaces, square controls, one restrained forest accent, and generous reading space. Do not use color alone to indicate state.”

Do this on one of your pages

  1. Pick a page whose purpose and reading order are already clear.
  2. Write three rules across type, geometry, surface/color, density, imagery, or motion.
  3. Apply the rules to one repeated element and one new section.
  4. Check that a heading, primary action, focus state, and error state are still recognizable without relying only on color.
