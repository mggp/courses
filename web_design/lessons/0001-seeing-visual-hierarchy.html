See the attention order

A page can be valid, responsive, and tasteful yet still feel wrong. Often the page has failed to decide what matters most.

Your win: diagnose a page's visual hierarchy and make one precise revision request.

Start with intent

Before styling a page, write its intended reading order as a sentence:

“People should notice the project promise, then the proof, then the action.”

This is a design contract. The rendered page either supports that order or it does not. Nielsen Norman Group defines visual hierarchy as arranging elements so the eye meets them in their intended order of importance.

Four variables do most of the early work: size, contrast, spacing, and position. None is inherently good. A large element is useful only when it deserves attention.

Use the three-pass test

  1. Name the intended order. Limit it to three beats. If everything matters equally, the page has no direction.
  2. Run the squint test. Blur your eyes or step back. Fine detail disappears, leaving the strongest masses and contrasts.
  3. Change one variable. Adjust scale, contrast, spacing, or position. Run the test again and describe what moved.

Contrast that helps attention is not the same as contrast required for legibility. A quiet paragraph may still need a text contrast ratio of at least 4.5:1 under WCAG 2.2's minimum contrast guidance.

Make the critique specific

“Make it pop” gives an AI no stable target. Give it an intended order, identify the conflict, and constrain the revision:

“The metadata and headline have similar visual weight, so the entry point is ambiguous. Make the headline dominant through type scale. Keep the palette and layout unchanged.”

That request is inspectable. You can compare the next result against the same contract.

Do this on one of your pages

  1. Open a page that has never felt right.
  2. Write the intended first, second, and third points of attention before looking closely.
  3. Squint at the page and record the actual order.
  4. Write one revision request using the model above. Change only one variable.
