Spacing creates groups

White space is not leftover room. It tells the reader which elements belong together before they read a word.

Your win: repair the grouping of a code-entry screen and describe the change as a relationship.

The rule is relative

People tend to perceive nearby elements as related and separated elements as different groups. This is the Gestalt principle of proximity. Nielsen Norman Group gives the same account in its three-minute proximity lesson.

Do not begin with “Should this gap be 16 or 24 pixels?” Begin with “Should this gap be smaller or larger than the one beside it?”

Label → fieldSmallest gap. The label identifies this control.
Instruction → formSmall gap. Both belong to the task.
Task → reassuranceLargest gap. This begins a new group.

Read spacing as nested scope

A label and input form the smallest unit. That unit joins the submit action to form a larger task group. The reassurance follows as a separate group. Each boundary needs more space than the relationships inside it.

This resembles nested scope in code. Indentation does not create program semantics, but it exposes them. Spacing does the same for interface structure.

W3C guidance for cognitive accessibility recommends visually grouping controls with the content they affect and using white space or dividers between separate regions.

Boxes are a stronger signal

A border or background creates a common region. Use it when proximity alone cannot keep a group intact, such as a dense dashboard. On a small form, another card inside the main card usually repeats what spacing already says.

Write the critique

“Equal vertical gaps make the instruction, form, and reassurance read as one group. Tighten the label-to-field gap, keep the instruction close to the form, and add more space before the reassurance. Keep type scale and color unchanged.”

Do this on your code screen

  1. Name every group without referring to its visual container.
  2. Find the smallest within-group gap and the smallest between-group gap.
  3. Check whether the between-group gap is clearly larger.
  4. Write one revision request that changes spacing only.
