Repeat the relationship

Visual rhythm lets a reader predict structure. It appears when equivalent relationships repeat their spacing, size, or form.

Your win: find a break in vertical rhythm and decide whether it carries meaning.

Rhythm is not uniform spacing

A page needs several gap sizes because it contains several relationships. A title sits close to its summary. One entry sits farther from the next. Rhythm comes from repeating each relationship consistently.

This is close to debugging an invariant. The invariant is not “every gap equals 8px.” It is “equivalent relationships use equivalent treatment.”

A scale supplies values; repetition creates rhythm

A spacing scale limits arbitrary choices. It does not tell you which value belongs to which relationship. GOV.UK ties its type-scale line heights to 5px multiples to create a consistent vertical rhythm. Material Design aligns components to an 8dp grid and type to a 4dp baseline grid. Both systems repeat shared measurements, but neither requires every interval to match.

Exceptions spend attention

A break in rhythm is useful when the structure changes: a new section begins, a featured item deserves emphasis, or an interruption requires action. If meaning stays the same, the break makes the reader pause for no payoff.

Write the critique

“The first two release titles sit 8px from their summaries, but the third uses 28px although its role is unchanged. Restore the 8px gap so equivalent entries repeat the same relationship.”

Do this on one of your pages

  1. Choose three repeated components, such as cards, rows, or form groups.
  2. Name one relationship inside them, such as label to value or title to summary.
  3. Measure that relationship in all three instances.
  4. For each exception, state what change in meaning it communicates. Remove it if you cannot.
