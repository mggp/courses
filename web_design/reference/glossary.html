Living reference

Web design field glossary

Observable language for discussing an interface. Each term includes a question you can apply to a page.

Visual hierarchy

The order in which a composition attracts attention and communicates importance.

Test: After three seconds, what did you notice first, second, and third?

Dominance

The degree to which one element attracts more attention than nearby elements.

Test: Is there one clear entry point, or are several elements shouting?

Contrast

A noticeable difference between elements, such as size, weight, value, color, shape, or spacing.

Test: Which difference is doing useful work, and which is decoration?

Proximity

The distance between elements, which suggests whether they belong together.

Test: Are related items closer to each other than to unrelated items?

Common region

A boundary, background, or container that makes enclosed elements appear related.

Test: Does this group need a container, or would spacing alone make the relationship clear?

Alignment

A shared visual edge or axis that makes relationships easier to scan.

Test: Can you trace a few strong invisible lines through the page?

Rhythm

A repeated pattern of spacing, size, or form that helps the reader predict structure.

Test: Do equivalent relationships use equivalent spacing?

Type role

A named text function, such as task heading, control label, or supporting copy, with a reusable visual treatment.

Test: Does this style express a repeatable job, or was it invented for one element?

Type scale

A limited set of font sizes used to distinguish text roles consistently.

Test: Are nearby sizes distinct enough to show a change in role?

Breakpoint

The available width where a composition changes because its current arrangement no longer works.

Test: Which content constraint fails on the other side of this value?

Reflow

The rearrangement of content to fit available space without losing information or requiring two-dimensional scrolling.

Test: Can a reader zoom or narrow the page and still reach everything by scrolling in one direction?

Interaction pattern

A familiar solution for a recurring user task, such as tabs for switching between peer views.

Test: Will people recognize how this behaves before trying it?

Interaction contract

The relationship among a control's cue, its behavior when activated, and the feedback that exposes the result.

Test: Does the control do what its appearance and context led you to predict?

Visual language

A repeatable set of visual rules that gives a product a recognizable voice.

Test: Can you name the rules without relying on a style label?
