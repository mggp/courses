Quick reference

Grouping without guesswork

Use distance to state relationships. Add a container only when distance cannot do the job alone.

1. Name the groups

Write what belongs together before moving anything. “Instruction and form” is a group. “Everything in the card” is usually too vague.

2. Compare gaps

Within-group gaps should be smaller than between-group gaps. The ratio matters more than a universal pixel value.

3. Check control ownership

Put a label close to its field and an action close to what it changes. Distance should not make people infer ownership.

4. Remove spare boxes

If spacing already makes a group clear, another border or background adds noise. Use common region when proximity is not enough.

A critique sentence

“Equal gaps make the task and reassurance read as one group. Tighten the label-to-field gap and increase the space before the reassurance.”
