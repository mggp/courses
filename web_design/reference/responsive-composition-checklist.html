Quick reference

Break where the content breaks

Choose responsive changes from layout constraints. Device labels are poor substitutes for inspecting the composition.

1. Name the regions

State the job and priority of each column. Decorative geometry is not a reason to preserve a layout.

2. Set minimum widths

Find the narrowest useful width for each region. Use real content and realistic control labels.

3. Add the budget

Combine region minimums, gaps, and insets. This estimates where the current composition stops fitting.

4. Sweep around the switch

Resize slowly above and below the estimate. Watch for awkward wrapping, crushed controls, and broken priority.

5. Check stacked order

Remove the columns mentally. The remaining document order should match the intended reading order.

6. Test the floor

At 320 CSS pixels, most vertical content must reflow without lost information or two-dimensional scrolling.

A critique sentence

“The columns persist below their minimum useful widths. Stack the secondary region when their width budget stops fitting, and preserve the primary-first source order.”
