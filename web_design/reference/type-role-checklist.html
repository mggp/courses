Quick reference

Typography by role

Name the job first. Choose values second. Reuse the result anywhere that job appears.

1. Name each role

Use names tied to purpose, such as task heading, section heading, control label, body copy, supporting copy, or metadata.

2. Compare neighbors

Ask whether nearby roles differ enough in size or weight. Do not evaluate a font value in isolation.

3. Protect readability

Quiet text with hierarchy, not punishment. Avoid tiny body copy, cramped multi-line text, and weak contrast.

4. Reuse the rule

Equivalent roles should use the same type style across screens. If one differs, state the reason.

5. Check semantics

Inspect heading levels separately from visual size. CSS can change emphasis, but it cannot repair the document outline.

6. Test overrides

Increase text spacing and zoom. Text must reflow without clipping, overlap, or lost controls.

A critique sentence

“These two roles use nearly identical typography, so their importance is unclear. Promote the task heading through size and keep the supporting copy readable. Change no other visual variable.”
