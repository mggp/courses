Glossary

The canonical language of this course. Every lesson uses these terms and only these terms. Definitions grow as your understanding does.

The retrieval pipeline

RAG (Retrieval-Augmented Generation): A pattern where a model answers a question by first pulling relevant excerpts from a document store, then generating a response conditioned on those excerpts. Avoid: "talking to your documents", "AI over your data".

Chunking: Splitting a source document into small pieces that can be retrieved independently. Avoid: "splitting", "segmentation".

Embedding: An array of numbers produced by an embedding model that maps text into a vector space where similar meaning sits nearby. Avoid: "vectorization" when you mean the model output.

Cosine similarity: The cosine of the angle between two vectors, used as a measure of how close two embeddings are; 1 means identical direction, 0 means orthogonal. Avoid: "score" without saying of what.

Retrieval: The step that embeds a query and returns the chunks whose vectors are closest to the query's vector.

Generation: The step that sends the retrieved chunks plus the question to a language model and gets back a grounded answer.

Grounding: Anchoring an answer in source material the model can be checked against, rather than its internal knowledge. Avoid: "making it factual".

Provenance: The identity of the chunk an answer came from, carried on every chunk (an id, later a source path). Retrieval without provenance is an answer without a citation. Avoid: "metadata" when you mean the citation trail.

Gold answer: A hand-written pair of a question and the exact sentence that must be retrieved to answer it. The unit you score retrieval against.

Recall@k: The fraction of gold chunks found in the top-k retrieved chunks, measured at the k you will actually feed the generator. 1.0 on an index smaller than k is vacuous.

Model vocabulary

Embedding model: A model trained to map text (and sometimes images) into a shared vector space. Avoid: "the encoder" unless you are discussing its internals.

Language model (LLM): A model that generates text given a prompt. In this course it is the generator in RAG, never the store of your data. Avoid: "the AI" when you mean a specific model.

Context window: The number of tokens a language model can take as input in one call — the reason retrieval must select a few chunks rather than dump a whole corpus in.

Token: A unit of text a model reads and writes — roughly a word fragment, not a word.

Hallucination: Confident output that does not match the source material or reality. RAG reduces — it does not eliminate — hallucination.

Where it lives

Vector store: Where chunk text and its embedding live together. For this course the default is a plain file or SQL table, not a dedicated vector database. Avoid: "vector DB" for any old place you kept a numpy array.

Embedding dimension: The fixed length of every vector an embedding model emits (e.g. 384 for all-MiniLM-L6-v2).

Ambiguities resolved in this course

"Retrieval" always means embedding search in this course — never keyword search. When both are combined (hybrid search), it is spelled out explicitly.

"Score" always means cosine similarity between two normalized vectors unless a different metric is named.
