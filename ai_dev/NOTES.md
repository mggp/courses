# Teaching Notes

## Learner profile

- Experienced Python + web developer (senior). Assume fluency with Python, APIs, databases, web apps.
- Knows AI *theory* and isolated concepts; the gap is *building* systems. "Knows what RAG is but couldn't build one."
- Already built one agent (validates tests generated by a coding agent) — has shipped something with LLMs.
- Cannot use AI at work (fintech compliance). All practice is personal/after-hours. Prefer local, low-cost setups.
- Wants skills he can use in the real world, tied to concrete products (language-learning app, fintech tooling).

## Teaching preferences observed

- Prefers direct instruction over Socratic questioning. Say "go on" — wants me to just build things.
- Values primary sources and citation over hand-waving. (Asked me not to peek at other workspaces; keep focus here.)
- Don't make him read other people's files/setups — treat this workspace as self-contained.

## Design choices to keep

- Build-from-scratch first (numpy, no frameworks) so the mechanics aren't hidden; introduce frameworks later once they'd be understood as shortcuts.
- Every lesson ties to the mission (language app / fintech / job market).
- Use retrieval practice quizzes with equal-length answers; tight feedback loops.
